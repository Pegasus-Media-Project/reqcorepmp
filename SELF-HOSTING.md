# Self-Hosting Reqcore (Discontinued)

Reqcore is closed-source, cloud-hosted SaaS. Self-hosting is **not supported** — there is no self-hosted or open-source edition of Reqcore.

This guide previously documented a self-hosting path from an earlier open-source release. That release has been discontinued (2026-06-30); the codebase is closed-source and maintained internally, and production runs exclusively as managed cloud deployment on Railway.

For deployment details, see [ARCHITECTURE.md](ARCHITECTURE.md).
